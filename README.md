# Timo Heimonen

Systems programming, reverse engineering, and minimalist software.

### Retro & Reverse Engineering (Amiga 68k)
Preserving and expanding classic Amiga titles by developing the world's first(community) native **in-game** editors and performance patches in Motorola 680x0 assembly. All released as open source under the MIT License:

* **[amiga-stunt-car-racer-060-performance-patch](https://github.com/timoheimonen/amiga-stunt-car-racer-060-performance-patch)** – 50 Hz physics, 50 FPS, and built-in in-game track editor.
* **[amiga-cannon-fodder-editor](https://github.com/timoheimonen/amiga-cannon-fodder-editor)** – First native in-game level editor for Amiga Cannon Fodder (WHDLoad-ready).
* **[Amiga-Lemmings-Editor](https://github.com/timoheimonen/Amiga-Lemmings-Editor)** – Integrated in-game level editor for Lemmings and Holiday Lemmings 1994.
* **[amiga-lemmings2-editor-patch](https://github.com/timoheimonen/amiga-lemmings2-editor-patch)** – Real-time in-game level editor patch for Lemmings 2: The Tribes.
* **[amiga-swos-9697-editor](https://github.com/timoheimonen/amiga-swos-9697-editor)** – Integrated in-game team, player, and tournament editor for Sensible World of Soccer 96/97 (Amiga A1200 / WHDLoad) with Python JSON/CSV toolchain.

### Modern Systems & Performance
* **[macOS-memory-benchmark](https://github.com/timoheimonen/macOS-memory-benchmark)** – Low-level command-line tool measuring CPU and Metal GPU memory bandwidth, synthetic LLM decode/prefill traffic, cache/main-memory latency, and TLB behavior on Apple Silicon (C++, ARM64 Assembly, Metal).

### Minimalist & Zero-Dependency Web
Lightweight, privacy-focused web tools built without frameworks, trackers, or telemetry:
* **[clocksimulator.com](https://clocksimulator.com)** – Open-source analog & digital canvas clock.
* **[diffvoid.com](https://diffvoid.com)** & **[writevoid.com](https://writevoid.com)** – Distraction-free, client-side productivity utilities.
* **[securememo.app](https://securememo.app)** – Client-side encrypted, self-destructing notes.
